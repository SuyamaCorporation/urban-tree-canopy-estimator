# Urban Tree Canopy Estimator

**Category:** Environmental & Sustainability Tools

Build a tree inventory and calculate annual carbon sequestration (kg CO₂), stormwater interception (liters), cooling energy savings (kWh), and canopy area (m²) for 9 urban tree species. Accounts for hardiness zone, setting (street/park/residential/commercial), trunk diameter, and age using i-Tree-derived coefficients. Shows real-world equivalencies (car km offset, flight hours, showers). All data persists in localStorage.
